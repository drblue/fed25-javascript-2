# Supabase Todos

A standard React TS-app created with Vite. The following packages are already installed:

* React Bootstrap
* React Router
* React Hook Form
* React Spinners
* React Toastify

## Installation

Create a new Supabase project. Copy `.env.example` to `.env` and fill in the **Project URL** and the **Publishable key** from the _Project Overview_ of the Supabase projectapp.

```zsh
npm install
```

## Run

```zsh
npm run dev
```

## Deploy

```zsh
npm run check
npm run build
```
