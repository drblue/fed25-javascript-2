# InstaMemes

A React app with Supabase for viewing and uploading memes. Fun-ness guaranteed!

## Installation

Create a new Supabase project. Copy `.env.example` to `.env.local` and fill in the **Project URL** and the **Publishable key** from the _Project Overview_ of the Supabase projectapp.

```zsh
npm install
cp .env.example .env.local
code .env.local
```

## Run

```zsh
npm run dev
```

## Deploy

```zsh
npm run check
npm run build
```
