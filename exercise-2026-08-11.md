# Övning 2026-08-11

## 1. 🎛️ Toggle todo

Skriv klart `handleToggle` så man kan uppdatera en todo's completed-status ifrån `TodoPage`. Glöm inte skåla med användaren (visa en toast 🥂).

## 2. ✍🏻 Redigera todo

Använd `useGetTodo` på `EditTodoPage` och skriv klart `updateTodo` så todo:ns nya titel sparas. Visa en toast + vidarebefordra besökaren till den enskilda todo:ns sida om uppdateringen lyckas.

Om uppdateringen misslyckas så visa ett felmeddelande i UI om detta.

## 3. 🧹 Radera todo

Skriv klart `handleDelete` så man kan radera en todo ifrån `TodoPage`. Så klart ska man vidarebefordras till listan över alla todos om raderingen lyckas.

Om uppdateringen misslyckas så visa ett felmeddelande i UI om detta.
