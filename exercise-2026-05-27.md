# Övning 2026-05-27

Lägg till funktionalitet i `08-react-query` för att söka efter nyheter från HackerNews. Du ska använda React Query för detta och `services/HackerNewsAPI.ts` samt `Pagination`-komponenten.

Det går fint att använda befintlig JSX från `07-hackernews/src/pages/SearchPage.tsx` men skriv om all logik så React Query används istället.

Glöm inte felhantering och att disable:a sök-knappen medan en sökning pågår.

## Steg 1

Börja med att lagra `query` och `page` i en state på sidan så du kan få pagineringen att fungera med React Query.

## Steg 2

Flytta så `query` ligger i `URLSearchParams` (via hook:en `useSearchParams`) istället för en state.

När sidan laddar in första gången ska en sökning ske **ENDAST** om `query` (från `URLSearchParams`) existerar och inte är tom.
