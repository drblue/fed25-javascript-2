## Steg 1. Redigera todo (för er som inte hann med den under måndagens korta övning)

1. När man klickar på "Edit" inne på en todo ska man komma till `/todos/<id>/edit`, t.ex. `/todos/5/edit`.

2. Ladda in respektive todo, t.ex. todo med id `5`.

3. Visa befintlig todo-titel i ett formulärfält.

4. När man klickar på Spara, skicka förfrågan till vårt API om att uppdatera `title` på t.ex. todo med id `5`.

5. Skicka besökaren tillbaka till den enskilda todon (efter att uppdatering är genomförd), t.ex. `/todos/5`.
   Glöm inte visa en bekräftelse för användaren!

6. Lägg in en knapp på Edit-sidan som tar användaren tillbaka till **föregående** sida.

### Steg 2. ConfirmationModal

Skapa komponenten `ConfirmationModal` som ska visa en `Modal` från React Bootstrap. Man ska kunna ange titel, variant (`success`, `warning` osv) och valfritt innehåll i `Modal.Body`. Man ska även kunna skicka in två funktioner, `onCancel` och `onConfirm` som modalen ska köra när man klickar på motsvarande knapp.

Exempel på hur jag vill kunna använda den:

```jsx
<Button
  onClick={() => setShowDeleteModal(true)}
  variant="danger"
>Delete</Button>

<ConfirmationModal
  onCancel={() => setShowDeleteModal(false)}
  onConfirm={() => handleDeleteTodo(todo)}
  show={showDeleteModal}
  title="Confirm delete"
  variant="danger"
>
  Delete todo "{todo.title}"?
</ConfirmationModal>
```
