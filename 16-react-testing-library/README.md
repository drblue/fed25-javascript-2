# 🧑🏻‍🔬 React Testing Library

Demo of using React Testing Library for testing React Components 🧑🏻‍🔬.

A copy of `15-redux-toolkit` but with some logic broken out into a few new components like `TodoCounter`, `TodoList` and `TodoListItem`.

## Packages

* `@testing-library/react`
* `@testing-library/dom`
* `@testing-library/jest-dom`
* `jest-environment-jsdom`
* `jsdom`
* `vitest`

## Installation

1. `npm install`

## Run

1. `npm run dev`

## Test

1. `npm run test`

## Build

1. `npm run check`
2. `npm run build`
